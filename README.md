## Tutor Setup

### Di folder utama
```sh
npm install tailwindcss @tailwindcss/vite
```

### Masuk folder spojedy

```sh
npm install
npm i @imagekit/vue
```

### Masuk folder backed

```sh
npm install express mongoose cors nodemon
```

## Tutor Jalanin

### Masuk folder spojedy

```sh
npm run dev (buat jalanin frontend)
```

### Masuk folder backed

```sh
npm run dev (buat jalanin server api backend)
```
