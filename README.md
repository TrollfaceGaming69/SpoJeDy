## Tutor Setup

### Di folder utama
```sh
npm install tailwindcss @tailwindcss/vite
```

### Masuk folder spojedy

```sh
npm install
npm i @imagekit/vue
```

### Masuk folder backed

```sh
npm install express mongoose cors nodemon bcrypt jsonwebtoken
npm install express-mongo-sanitize express-rate-limit 
```

### Tambah Mongo URI dan token JWT di .env

```sh
MONGO_URI=mongodb+srv://santoso:<password>@spojedycluster.ywus1cc.mongodb.net/?appName=<AppName>
(ganti <passowrd> dan <AppName>)
```

## Tutor Jalanin

### Masuk folder spojedy

```sh
cd spojedy
npm run dev (buat jalanin frontend)
```

### Masuk folder backed (buka terminal baru)

```sh
cd backend
npm run dev (buat jalanin server api backend)
```
